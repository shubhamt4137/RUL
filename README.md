# Motor Remaining Useful Life (RUL) Prediction

## Overview
This project predicts the Remaining Useful Life (RUL) of industrial motors using Machine Learning techniques.

## Features
- Data preprocessing and feature engineering
- Random Forest Regression
- Predictive maintenance
- RMSE and R² evaluation
- Maintenance recommendation

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
